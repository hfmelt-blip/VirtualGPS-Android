# VirtualGPS

تطبيق Android مفتوح المصدر بلغة Kotlin، بواجهة عربية، لاختيار إحداثيات وحفظ مواقع مفضلة ومحاكاة مزوّد GPS عبر واجهات Android الرسمية فقط.

## الميزات

- خريطة OpenStreetMap عبر osmdroid مع الإسناد الظاهر، بلا API key.
- اختيار نقطة بالنقر أو الضغط المطوّل، أو إدخال الإحداثيات يدوياً، مع دعم الأرقام العربية والفارسية.
- حفظ المواقع المفضلة واختيارها وحذفها محلياً باستخدام SharedPreferences.
- خدمة أمامية تبث موقع GPS كل ثانية مع إشعار وزر إيقاف، وتزيل مزوّد الاختبار عند إيقافها.
- لا تسجيل دخول، لا خادم، لا توكنات ولا مفاتيح API. لا إخفاء لمحاكاة الموقع ولا تجاوز لفحوصات التطبيقات.

## الحصول على APK

افتح [Actions](https://github.com/hfmelt-blip/VirtualGPS-Android/actions)، ثم أحدث تشغيل ناجح لـ **Android Debug APK**، ومن **Artifacts** حمّل **VirtualGPS-debug**، وفك ZIP وثبّت `app-debug.apk`.

يبني GitHub نسخة Debug موقعة بمفتاح تطوير مؤقت يولّده Android SDK على runner. ليس مفتاح إصدار خاصاً. قد تحتاج لإزالة النسخة السابقة عند اختلاف مفتاح Debug بين عمليات البناء، وستفقد المفضلة عند الإزالة.

## التشغيل على الهاتف

1. ثبّت APK واسمح بالتثبيت من المصدر الذي حمّلته منه.
2. فعّل خيارات المطوّر: الإعدادات ← حول الهاتف ← معلومات البرنامج ← اضغط رقم الإصدار سبع مرات (قد تختلف الأسماء حسب الهاتف).
3. من خيارات المطوّر اختر **تحديد تطبيق الموقع الوهمي / Select mock location app** ثم **VirtualGPS**.
4. فعّل الموقع في الهاتف وافتح التطبيق. اختر نقطة بالخريطة أو أدخل خط العرض وخط الطول.
5. اضغط بدء المحاكاة وامنح إذن **الموقع الدقيق** ثم اضغط بدء مجدداً. اسمح بالإشعارات لإظهار زر الإيقاف بسهولة.
6. يعرض شريط الحالة نجاح التشغيل أو سبب فشله. أثناء التشغيل، اختيار نقطة جديدة لا يغيّر البث حتى تضغط **بدء / تحديث المحاكاة**.
7. للإيقاف استخدم زر التطبيق أو الإشعار. الخدمة لا تبدأ عند إقلاع الهاتف، ولا تُعاد تلقائياً بعد إنهاء العملية.

المحاكاة معلّمة رسمياً كموقع اختبار ويمكن للتطبيقات اكتشافها أو رفضها. التطبيق يحاكي `LocationManager.GPS_PROVIDER` فقط؛ لا يضمن التأثير في جميع التطبيقات أو مصادر الموقع المدمجة أو الشبكية، ولا يغيّر عنوان IP أو إعدادات VPN. عند إنهاء العملية قسرياً يدير Android تنظيف مزوّد الاختبار؛ إن تأخر رجوع الموقع الحقيقي أوقف المحاكاة وأعد تفعيل الموقع.

## الخريطة والخصوصية

تحتاج الخريطة الإنترنت لتنزيل البلاطات؛ إدخال الإحداثيات والمفضلة والمحاكاة تعمل دون خريطة محمّلة. تنزيل البلاطات يرسل عنوان IP ومناطق البلاطات المطلوبة إلى خوادم OpenStreetMap. لا يوجد رفع للمفضلة إلى خادم للتطبيق، والنسخ الاحتياطي التلقائي معطّل. يستخدم التطبيق HTTPS وذاكرة osmdroid المخبأة، ولا يوفر تنزيل مناطق جماعي أو استعمالاً دون اتصال مضموناً.

البيانات © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright). يرجى مراعاة [سياسة خادم البلاطات](https://operations.osmfoundation.org/policies/tiles/)؛ الخدمة المجانية بلا ضمان توافر.

## البناء والتحقق

- JDK 17، Gradle 8.9، Android SDK 35، Build tools 35.0.0.
- Android Gradle Plugin 8.7.3، Kotlin 2.0.21، osmdroid 6.1.20.
- Android 8.0 (API 26) فما فوق؛ target SDK 35.
- بعد تثبيت Gradle 8.9 وAndroid SDK وتحديد `ANDROID_HOME`، نفّذ:

```sh
gradle --no-daemon testDebugUnitTest lintDebug assembleDebug
```

يستخدم CI إصدار Gradle محدداً عبر setup-gradle؛ لا يتطلب Gradle wrapper أو ملفات سرية. الناتج: `app/build/outputs/apk/debug/app-debug.apk`. يمكن تشغيل workflow يدوياً من Actions، ويعمل أيضاً عند push إلى main وpull request. صلاحية workflow هي `contents: read` فقط ولا يحتاج Secrets.

اختبارات JUnit تتحقق من حدود الإحداثيات ورفض القيم غير المحدودة والمدخلات غير الصالحة ودعم الأرقام العربية والفارسية. فحص lint والبناء لا يعوّضان اختبار هاتف فعلي. انظر [قائمة الاختبار اليدوي](docs/TESTING.md).

## مكونات المشروع

- `MainActivity.kt`: واجهة عربية، خريطة، أذونات، حفظ واختيار المفضلة، بدء وإيقاف الخدمة.
- `Coordinates.kt`: التحويل والتحقق من حدود الإحداثيات.
- `LocationStore.kt`: تخزين محلي خاص بالتطبيق.
- `MockLocationService.kt`: إشعار وخدمة foreground، إنشاء test provider، إرسال Location بوقت حالي وelapsed realtime، والتنظيف عند الإيقاف.
- `.github/workflows/android.yml`: اختبارات، lint، بناء ورفع APK وتقارير التحقق.

واجهات رسمية: [LocationManager](https://developer.android.com/reference/android/location/LocationManager)، [خدمات foreground من نوع location](https://developer.android.com/develop/background-work/services/fgs/service-types#location).
